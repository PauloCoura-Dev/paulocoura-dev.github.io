Caminho de um relatório mensal

┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│   envio    │────▶│ validação  │────▶│   ateste   │────▶│   E-Docs   │────▶│   folha    │
│pesquisador │     │supervisão  │     │coordenação │     │ assinatura │     │ pagamento  │
└────────────┘     └────────────┘     └────────────┘     └────────────┘     └────────────┘
  • Ateste em vários níveisCoordenação, Gerência e Direção atestam o relatório, com regras por perfil e escalonamento quando falta responsável.
  • Integração com o E-DocsCaptura, assinatura digital e tramitação dos documentos pela API do sistema de processos do Governo do ES.
  • Dados pessoais criptografadosAES-256 em repouso. O CPF é buscado por hash HMAC e nunca fica em texto aberto no banco. LGPD desde o desenho.
  • Login pelo Acesso CidadãoOAuth do governo estadual, com lista de CPFs autorizados e perfis de acesso.
  • Folha de pagamento das bolsasPrévia gravada, folha suplementar no mesmo período e arquivo de pagamento com crédito em conta de qualquer banco.
  • Configurável sem deployA equipe monta perfis de acesso e formulários de cadastro versionados direto pela tela.
  • API para outros sistemasToken por sistema parceiro, permissões por grupo de dados e sincronização incremental.
  • Microsserviço de PDFServiço em Node.js que gera os documentos oficiais usados na homologação e no fluxo de relatórios.

O código pertence ao Governo do Espírito Santo, por isso não há link para o repositório. Mostro a arquitetura e as decisões técnicas numa conversa.

Projeto pessoal

SheetMind

Para micro e pequenas empresas que vivem de planilha. Você envia o arquivo e o sistema diz o quanto dá para confiar nos dados, onde estão os problemas e como corrigir. Depois monta os gráficos sozinho, só com o que está na planilha.

  • Nota de confiabilidade de 0 a 100Encontra colunas vazias, excesso de células em branco, texto misturado com número e linhas duplicadas, e sugere a correção de cada um.
  • Gráficos escolhidos pelo tipo do dadoData com valor vira linha no tempo, categoria vira barras ou pizza, dois números viram dispersão. Nenhum gráfico usa dado que não está no arquivo.
  • Insights em linguagem simplesA API do Claude recebe só o resumo da planilha e devolve de 3 a 6 recomendações práticas, sem jargão.
